Execution Surface

target repo

실제 구현은 이 외부 레포에서 일어난다.

target-repo/
├── src/ or app/
├── tests/
├── docs/ or specs/
├── .github/ or CI config/
└── deploy/runtime assets/
Agent project
사용자와 가장 먼저 만나는 레이어라서 `README`, `.agent/skills`, `scripts`, `tests`가 모두 시작 규칙과 bootstrap 품질을 직접 담당한다.
Context monorepo
실제 깊이는 `docs/root`, `docs/services`, `docs/templates`에 몰려 있다. top-level `apps/packages/services/contracts`는 현재 구조 앵커 성격이 강하다.
Change control
현재 트리는 가볍지만 의미는 무겁다. `changes`와 `releases/*`는 실행 evidence가 쌓이는 ledger anchor다.
Target repo
control-plane 3레포가 여기로 handoff 한다. 코드, 테스트, 빌드, deploy 세부는 이 레포의 책임이다.
