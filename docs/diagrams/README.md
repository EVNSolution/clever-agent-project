# 시나리오 다이어그램

`clever-agent-project`의 시작점과 3레포 제어 평면을 빠르게 설명하기 위한 다이어그램 모음이다. 현재 기본 출력은 저장소 화면에서 바로 읽히는 Markdown + Mermaid다.

## 저장소 화면용 다이어그램

- [clever-control-plane-overview.md](./clever-control-plane-overview.md): 3레포와 대상 레포지토리를 레포 수준에서 디렉터리 수준까지 내려서 보여주는 구조도
- [clever-work-lifecycle.md](./clever-work-lifecycle.md): 세션 시작, 3단계 하드 게이트, `project-start`, 범위가 고정된 변경, 대상 레포지토리 handoff를 실제 디렉터리/파일 기준으로 보여주는 실행도
- [clever-repo-directory-map.md](./clever-repo-directory-map.md): 3레포와 대상 레포지토리를 트리 시점에서 보는 구조 지도

## 로컬 상세 버전

- [clever-control-plane-overview.html](./clever-control-plane-overview.html): 로컬 브라우저에서 보는 상세 HTML 버전
- [clever-work-lifecycle.html](./clever-work-lifecycle.html): 로컬 브라우저에서 보는 상세 HTML 버전
- [clever-repo-directory-map.html](./clever-repo-directory-map.html): 로컬 브라우저에서 보는 상세 HTML 버전

## 참고

- 시각 스타일은 프로젝트 루트에 clone한 `diagram-design/` 레퍼런스를 따라 수작업으로 구성했다.
- Markdown 다이어그램은 저장소 화면에서 바로 렌더링되는 것을 우선 기준으로 둔다.
- HTML 다이어그램은 standalone 파일이라 로컬 브라우저에서 바로 열 수 있다.
