CLEVER 시작 도우미

짧게 입력하면 에이전트용 작업 프롬프트를 생성합니다.

작업 경로 입력은 제거했습니다. 실행 환경별 시작 방식만 안내합니다.

1. 작업 요약

가장 먼저 하려는 일만 적어 주세요. 나머지는 모르면 비워도 됩니다.

2. 작업 분류

정확하지 않아도 됩니다. 에이전트가 이후 startup branch state로 다시 정규화합니다.

3. 대상과 현재 상태

서비스 이름, repo, 화면, API, Figma, 회의 메모, 에러 로그를 자유롭게 한곳에 모읍니다.

4. 제약사항

필요한 제약만 적기

5. 실행 환경

사용 환경을 선택하면, 사용자가 먼저 해야 할 시작 위치 안내와 에이전트용 프롬프트가 함께 바뀝니다.

6. 생성 프롬프트

아래 생성 프롬프트를 사용할 에이전트 채팅창에 붙여넣어 주세요.

터미널/VS Code의 시작 위치는 사용자가 먼저 준비하고, Application은 에이전트가 먼저 디렉터리를 질문하도록 지시합니다.
